# Experimental PCM protocol v1 — draft offline contract
Transport: Linux AF_UNIX SOCK_SEQPACKET. Parent directory must be owned by daemon UID, mode 0700; socket 0600; peer UID must match daemon UID using SO_PEERCRED. One live writer; second writer is closed. Existing paths are not unlinked at Open. Owned socket is removed on Close.

Every data packet is exactly 704 bytes: 64-byte little-endian header plus 640 bytes PCM16LE. Header:
offset 0 magic EPCS (4); 4 version u16=1; 6 header bytes u16=64; 8 rate u32=16000; 12 channels u16=1; 14 encoding u16=1; 16 samples u16=320; 18 flags u16=0; 20 generation u64 nonzero; 28 sequence u64 starting zero; 36 source sample index u64 starting zero; 44 CLOCK_MONOTONIC nanoseconds u64 for first sample; 52 reserved u64=0; 60 reserved u32=0.
No wall clock, length-prefixed allocations, factory data or raw channels.

A connection defines a single generation; the first valid generation must strictly increase over every previously accepted connection for this consumer lifetime. Sequence and sample index must advance exactly +1/+320; timestamps must advance +20ms within 2ms jitter from the initial source sample anchor. New generation requires reconnect. Max accepted age 80ms; max future skew 5ms; receiver checks freshness again at selection. All header fields and MSG_TRUNC are validated. Bad packet, ordering, timebase, timeout, queue overflow or EOF invalidates the session and discards queued data. Three consecutive capture ticks warm up before replacement. Packet framing itself is the versioned format/handshake: first packet seq/sample=0 is the announcement, no ACK; successful activation is verified by offline instrumentation. Authentication is local UID/path authorization, not a cryptographic boundary against same-UID compromise.
